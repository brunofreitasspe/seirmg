# Agente de IA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evoluir `features/ferramentas-ia` (hoje: um prompt único enviado pra API, sem ferramentas) pra um agente de verdade — motor de tool-calling real via API da Anthropic, gate de aprovação antes de qualquer escrita no SEI, desfazer, rastreamento de custo em tokens/R$, skills (personas configuráveis) e fluxos (sequência de passos revisável, "Estúdio" simplificado).

**Architecture:** Mesmo padrão arquitetural do resto do repo: toda decisão (quais ferramentas existem, o que custa, o que pode ou não executar sozinho, o que vira ação reversível) é função pura em `features/agente-ia/*.ts`. A página do agente (`src/agente-ia/`, aberta em aba própria — mesmo molde de `src/dashboard/` e `src/ferramentas-pdf/`) roda o loop manual de tool-calling chamando a API via o relay já existente (`background/index.ts`, mensagem `seirmg:fetch-ia` — **nenhuma mudança no background é necessária**, o handler já aceita qualquer `url/method/headers/body`). Escopo do motor nesta v1: **3 ferramentas de leitura + 1 de escrita totalmente reversível** (`adicionar_favorito`) — o catálogo cresce depois; não é honesto fingir que o agente já sabe assinar/tramitar documento sem o mesmo trabalho de reverse engineering que `sei-nucleo/dominio/*.ts` representa no projeto de referência.

**Tech Stack:** TypeScript, Vitest, fetch via `chrome.runtime.sendMessage({type: 'seirmg:fetch-ia', ...})`, API Anthropic Messages (`/v1/messages`, tool use).

**Spec:** Sem spec prévia — nasceu de comparação ad-hoc com `C:\sei\seipro\sei-pro\agente-ia\` nesta conversa, com decisões de escopo explícitas tomadas durante o brainstorm (registradas abaixo).

## Global Constraints

- **Decisão de escopo 1 (provedor):** o Agente de IA só funciona com a chave Claude (Anthropic) do próprio usuário, colada nas opções — não com OpenAI/Gemini. `features/ferramentas-ia` (prompt único, qualquer provedor) continua existindo sem mudança nenhuma; são features distintas, lado a lado.
- **Decisão de escopo 2 (Estúdio):** "fluxo" é uma lista ordenada de passos (cada passo = uma instrução enviada ao agente, com pausa pra revisão antes do próximo) — **não** um editor visual de canvas com setas/nós. O editor visual fica fora do escopo deste plano.
- **Decisão de escopo 3 (MCP):** sem protocolo MCP de verdade — "ferramenta" aqui é só uma entrada no catálogo interno (`features/agente-ia/tools.ts`) com JSON Schema + função `executar`, no formato nativo de tool use da API Anthropic.
- **Gate de aprovação é por ferramenta, não por chamada:** toda ferramenta tem `escrita: boolean` no catálogo. `escrita: false` executa sozinha; `escrita: true` **sempre** para o loop e espera clique explícito do usuário, sem excessão.
- Nenhuma chave de API nem corpo de requisição vai pra `console.log` nem pra qualquer lugar fora do `chrome.storage.sync` (mesmo padrão já usado por `ferramentasIA.{openai,gemini,claude}.apiKey`).
- `bun run test`, `bun run typecheck`, `bun run lint` passam a cada tarefa antes do commit.

```typescript
// src/features/agente-ia/tools.ts
import { adicionarFavoritoSeNovo } from '../controle-processos/favoritos'
import type { createLocalConfigStore, createSyncConfigStore } from '../../lib/storage'

export interface FerramentaAgenteDescricao {
  id: string
  nome: string
  descricao: string
  escrita: boolean
  inputSchema: Record<string, unknown>
}

export interface ContextoFerramenta {
  syncStore: ReturnType<typeof createSyncConfigStore>
  localStore: ReturnType<typeof createLocalConfigStore>
}

const FERRAMENTAS: FerramentaAgenteDescricao[] = [
  {
    id: 'listar_processos_favoritos',
    nome: 'Listar processos favoritos',
    descricao: 'Lista os processos marcados como favoritos pelo usuário, com número e especificação.',
    escrita: false,
    inputSchema: { type: 'object', properties: {}, additionalProperties: false },
  },
  {
    id: 'listar_historico_visitados',
    nome: 'Listar processos visitados recentemente',
    descricao: 'Lista os últimos processos que o usuário abriu (processos sigilosos nunca entram nessa lista).',
    escrita: false,
    inputSchema: { type: 'object', properties: {}, additionalProperties: false },
  },
  {
    id: 'consultar_status_bloco_assinatura',
    nome: 'Consultar status do bloco de assinatura',
    descricao: 'Informa se há documentos pendentes de assinatura pra área do usuário.',
    escrita: false,
    inputSchema: { type: 'object', properties: {}, additionalProperties: false },
  },
  {
    id: 'adicionar_favorito',
    nome: 'Adicionar processo aos favoritos',
    descricao: 'Marca um processo como favorito, pelo número do processo.',
    escrita: true,
    inputSchema: {
      type: 'object',
      properties: { numero: { type: 'string', description: 'Número do processo, no formato do SEI.' } },
      required: ['numero'],
      additionalProperties: false,
    },
  },
]

export function listarFerramentasAgente(): FerramentaAgenteDescricao[] {
  return FERRAMENTAS
}

export async function executarFerramenta(id: string, input: unknown, contexto: ContextoFerramenta): Promise<unknown> {
  if (id === 'listar_processos_favoritos') {
    const sync = await contexto.syncStore.get()
    return sync.controleProcessos.favoritos.itens.map((item) => ({ numero: item.numero, especificacao: item.especificacao }))
  }

  if (id === 'listar_historico_visitados') {
    const local = await contexto.localStore.get()
    return (local.historicoProcessosVisitados ?? []).map((item) => ({ numero: item.numero, tipo: item.tipo }))
  }

  if (id === 'consultar_status_bloco_assinatura') {
    // Implementação real precisa do mesmo fetch-via-background que popup/main.ts já faz
    // via consultarBlocosAoVivo (features/bloco-assinatura/consultarAoVivo.ts) -- não
    // reimplementar aqui, importar e reaproveitar.
    throw new Error('not implemented — ver Task 5, Step 3 (ligação do motor com o background)')
  }

  if (id === 'adicionar_favorito') {
    const { numero } = input as { numero: string }
    if (!numero) throw new Error('Parâmetro "numero" é obrigatório.')
    const atual = await contexto.syncStore.get()
    const novosItens = adicionarFavoritoSeNovo(atual.controleProcessos.favoritos.itens, {
      numero,
      link: null,
      adicionadoEm: new Date().toISOString(),
    })
    await contexto.syncStore.set({
      ...atual,
      controleProcessos: { ...atual.controleProcessos, favoritos: { ...atual.controleProcessos.favoritos, itens: novosItens } },
    })
    return { ok: true, numero }
  }

  throw new Error(`Ferramenta desconhecida: ${id}`)
}
```

- [ ] **Step 3: Implementar**

Preços copiados da tabela oficial vigente (Anthropic, US$ por milhão de tokens) — revisar esta constante quando os preços mudarem, é a única fonte de verdade do cálculo:

```typescript
// src/features/agente-ia/custo.ts
import type { AgenteIAUsoAcumulado, UsoModeloAgenteIA } from '../../lib/storage'

export const PRECO_POR_MODELO: Record<string, { inputUsdPorMilhao: number; outputUsdPorMilhao: number }> = {
  'claude-opus-5': { inputUsdPorMilhao: 5, outputUsdPorMilhao: 25 },
  'claude-sonnet-5': { inputUsdPorMilhao: 2, outputUsdPorMilhao: 10 },
  'claude-haiku-4-5': { inputUsdPorMilhao: 1, outputUsdPorMilhao: 5 },
}

export function calcularCustoUsd(modelo: string, inputTokens: number, outputTokens: number): number {
  const preco = PRECO_POR_MODELO[modelo]
  if (!preco) return 0
  return (inputTokens * preco.inputUsdPorMilhao + outputTokens * preco.outputUsdPorMilhao) / 1_000_000
}

export function acumularUso(
  atual: AgenteIAUsoAcumulado,
  modelo: string,
  uso: UsoModeloAgenteIA
): AgenteIAUsoAcumulado {
  const anterior = atual.porModelo[modelo] ?? { inputTokens: 0, outputTokens: 0 }
  return {
    porModelo: {
      ...atual.porModelo,
      [modelo]: {
        inputTokens: anterior.inputTokens + uso.inputTokens,
        outputTokens: anterior.outputTokens + uso.outputTokens,
      },
    },
  }
}
```

```typescript
import type { UsoModeloAgenteIA } from '../../lib/storage'

export type BlocoConteudo =
  | { type: 'text'; text: string }
  | { type: 'tool_use'; id: string; name: string; input: unknown }

  method: 'POST'
  headers: Record<string, string>

  modelo: string
  systemPrompt: string
  ferramentas: FerramentaAgenteDescricao[]
  mensagens: MensagemAgente[]
}): RequisicaoAgente {

    url: 'https://api.anthropic.com/v1/messages',
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-api-key': opcoes.apiKey,
      'anthropic-version': '2023-06-01',
    },

      model: opcoes.modelo,
      max_tokens: 4096,
      system: opcoes.systemPrompt,
      tools: opcoes.ferramentas.map((f) => ({ name: f.id, description: f.descricao, input_schema: f.inputSchema })),
      messages: opcoes.mensagens,

  }
}

  blocos: BlocoConteudo[]
  stopReason: string
  uso: UsoModeloAgenteIA
}

  content: BlocoConteudo[]
  stop_reason: string
  usage: { input_tokens: number; output_tokens: number }
}

export function extrairBlocos(corpoResposta: string): RespostaExtraida {
```

```typescript
// src/features/agente-ia/loop.ts
import type { BlocoConteudo, RespostaExtraida } from './mensagens'
import type { FerramentaAgenteDescricao } from './tools'

export interface ChamadaFerramenta {
  id: string
  name: string
  input: unknown
}

export type DecisaoLoop =
  | { tipo: 'fim' }
  | { tipo: 'executar_leitura'; chamadas: ChamadaFerramenta[] }
  | { tipo: 'pedir_aprovacao'; chamadas: ChamadaFerramenta[] }

function ehToolUse(bloco: BlocoConteudo): bloco is { type: 'tool_use'; id: string; name: string; input: unknown } {
  return bloco.type === 'tool_use'
}

export function decidirProximoPasso(resposta: RespostaExtraida, ferramentas: FerramentaAgenteDescricao[]): DecisaoLoop {
  const chamadas = resposta.blocos.filter(ehToolUse)
  if (chamadas.length === 0) return { tipo: 'fim' }

  const porId = new Map(ferramentas.map((f) => [f.id, f]))
  const descritas = chamadas.map((chamada) => {
    const ferramenta = porId.get(chamada.name)
    if (!ferramenta) throw new Error(`O agente tentou chamar uma ferramenta desconhecida: "${chamada.name}".`)
    return { chamada, ferramenta }
  })

  // Qualquer ferramenta de escrita no turno exige aprovação -- nunca executa a de escrita
  // "de carona" com as de leitura do mesmo turno.
  const temEscrita = descritas.some(({ ferramenta }) => ferramenta.escrita)
  const chamadasSimples: ChamadaFerramenta[] = chamadas.map((c) => ({ id: c.id, name: c.name, input: c.input }))

  return temEscrita ? { tipo: 'pedir_aprovacao', chamadas: chamadasSimples } : { tipo: 'executar_leitura', chamadas: chamadasSimples }
}
```

```typescript
// src/features/agente-ia/desfazer.ts
import type { AcaoAgenteParaDesfazer } from '../../lib/storage'

export function registrarAcaoParaDesfazer(
  historico: AcaoAgenteParaDesfazer[],
  acao: Omit<AcaoAgenteParaDesfazer, 'id' | 'criadoEm'>,
  criadoEm: string,
  limite = 20
): AcaoAgenteParaDesfazer[] {
  const completa: AcaoAgenteParaDesfazer = { ...acao, id: crypto.randomUUID(), criadoEm }
  return [completa, ...historico].slice(0, limite)
}

export function consumirAcaoParaDesfazer(
  historico: AcaoAgenteParaDesfazer[],
  id: string
): { acao: AcaoAgenteParaDesfazer | null; historico: AcaoAgenteParaDesfazer[] } {
  const acao = historico.find((item) => item.id === id) ?? null
  if (!acao) return { acao: null, historico }
  return { acao, historico: historico.filter((item) => item.id !== id) }
}
```

```typescript
import { createSyncConfigStore } from '../lib/storage'
import type { FluxoAgenteIA } from '../lib/storage'

async function render(): Promise<void> {
  const container = document.getElementById('conteudo')
  if (!container) return
  const store = createSyncConfigStore()
  const config = await store.get()
  let fluxos = config.agenteIA.fluxos

  function renderizarLista(): void {
    container!.innerHTML = ''
    fluxos.forEach((fluxo, indiceFluxo) => {
      const secao = document.createElement('section')
      const titulo = document.createElement('input')
      titulo.value = fluxo.nome
      titulo.addEventListener('change', () => {
        fluxos = fluxos.map((f, i) => (i === indiceFluxo ? { ...f, nome: titulo.value } : f))
        salvar()
      })
      secao.appendChild(titulo)

      const listaPassos = document.createElement('ol')
      fluxo.passos.forEach((passo, indicePasso) => {
        const li = document.createElement('li')
        const campo = document.createElement('textarea')
        campo.value = passo.instrucao
        campo.addEventListener('change', () => {
          fluxos = fluxos.map((f, i) =>
            i === indiceFluxo ? { ...f, passos: f.passos.map((p, j) => (j === indicePasso ? { instrucao: campo.value } : p)) } : f
          )
          salvar()
        })
        li.appendChild(campo)
        listaPassos.appendChild(li)
      })
      secao.appendChild(listaPassos)

      const btnPasso = document.createElement('button')
      btnPasso.textContent = '+ Passo'
      btnPasso.addEventListener('click', () => {
        fluxos = fluxos.map((f, i) => (i === indiceFluxo ? { ...f, passos: [...f.passos, { instrucao: '' }] } : f))
        renderizarLista()
        salvar()
      })
      secao.appendChild(btnPasso)
      container!.appendChild(secao)
    })

    const btnNovoFluxo = document.createElement('button')
    btnNovoFluxo.textContent = '+ Novo fluxo'
    btnNovoFluxo.addEventListener('click', () => {
      fluxos = [...fluxos, { id: crypto.randomUUID(), nome: 'Novo fluxo', passos: [] }]
      renderizarLista()
      salvar()
    })
    container!.appendChild(btnNovoFluxo)
  }

  async function salvar(): Promise<void> {
    const atual = await store.get()
    await store.set({ ...atual, agenteIA: { ...atual.agenteIA, fluxos } })
  }

  renderizarLista()
}
```

```typescript
// src/agente-ia/main.ts
import { createLocalConfigStore, createSyncConfigStore } from '../lib/storage'
import { listarFerramentasAgente, executarFerramenta } from '../features/agente-ia/tools'
import { montarRequisicaoAgente, extrairBlocos, type MensagemAgente, type BlocoConteudo } from '../features/agente-ia/mensagens'
import { decidirProximoPasso } from '../features/agente-ia/loop'
import { encontrarSkillAtiva, ferramentasPermitidasParaSkill } from '../features/agente-ia/skills'
import { calcularCustoUsd, acumularUso } from '../features/agente-ia/custo'
import { registrarAcaoParaDesfazer } from '../features/agente-ia/desfazer'

interface RespostaFetchIA {
  ok: boolean
  data?: string
  error?: string
}

async function chamarApi(requisicao: ReturnType<typeof montarRequisicaoAgente>): Promise<string> {
  const resposta: RespostaFetchIA = await chrome.runtime.sendMessage({
    type: 'seirmg:fetch-ia',
    url: requisicao.url,
    method: requisicao.method,
    headers: requisicao.headers,
    body: requisicao.body,
  })
  if (!resposta.ok || !resposta.data) throw new Error(resposta.error ?? 'Falha desconhecida ao chamar a API.')
  return resposta.data
}

function adicionarMensagemNaTela(role: string, texto: string): void {
  const conversa = document.getElementById('conversa')
  if (!conversa) return
  const bolha = document.createElement('p')
  bolha.className = `bolha bolha-${role}`
  bolha.textContent = texto
  conversa.appendChild(bolha)
}

async function rodarTurno(mensagens: MensagemAgente[]): Promise<MensagemAgente[]> {
  const syncStore = createSyncConfigStore()
  const localStore = createLocalConfigStore()
  const config = await syncStore.get()
  const skill = encontrarSkillAtiva(config.agenteIA.skills, config.agenteIA.skillAtivaId)
  const ferramentasPermitidas = ferramentasPermitidasParaSkill(skill, listarFerramentasAgente())

  const requisicao = montarRequisicaoAgente({
    apiKey: config.agenteIA.apiKey,
    modelo: config.agenteIA.modelo,
    systemPrompt: skill.systemPrompt,
    ferramentas: ferramentasPermitidas,
    mensagens,
  })

  const corpoResposta = await chamarApi(requisicao)
  const extraida = extrairBlocos(corpoResposta)

  const local = await localStore.get()
  await localStore.set({
    ...local,
    agenteIAUsoAcumulado: acumularUso(local.agenteIAUsoAcumulado ?? { porModelo: {} }, config.agenteIA.modelo, extraida.uso),
  })
  atualizarCustoNaTela(await localStore.get())

  const textoResposta = extraida.blocos.filter((b): b is { type: 'text'; text: string } => b.type === 'text').map((b) => b.text).join('\n')
  if (textoResposta) adicionarMensagemNaTela('agente', textoResposta)

  const mensagensComResposta: MensagemAgente[] = [...mensagens, { role: 'assistant', content: extraida.blocos }]
  const decisao = decidirProximoPasso(extraida, ferramentasPermitidas)

  if (decisao.tipo === 'fim') return mensagensComResposta

  if (decisao.tipo === 'pedir_aprovacao') {
    return aguardarAprovacao(mensagensComResposta, decisao.chamadas, ferramentasPermitidas)
  }

  // tipo === 'executar_leitura': roda sozinho e já alimenta o próximo turno.
  const resultados: BlocoConteudo[] = []
  for (const chamada of decisao.chamadas) {
    try {
      const resultado = await executarFerramenta(chamada.name, chamada.input, { syncStore, localStore })
      resultados.push({ type: 'tool_result', tool_use_id: chamada.id, content: JSON.stringify(resultado) })
    } catch (error) {
      resultados.push({ type: 'tool_result', tool_use_id: chamada.id, content: String(error), is_error: true })
    }
  }
  return rodarTurno([...mensagensComResposta, { role: 'user', content: resultados }])
}

async function aguardarAprovacao(
  mensagensAteAqui: MensagemAgente[],
  chamadas: Array<{ id: string; name: string; input: unknown }>,
  ferramentasPermitidas: ReturnType<typeof ferramentasPermitidasParaSkill>
): Promise<MensagemAgente[]> {
  const painel = document.getElementById('aprovacao-pendente')!
  painel.hidden = false
  painel.innerHTML = ''

  return new Promise((resolve) => {
    chamadas.forEach((chamada) => {
      const ferramenta = ferramentasPermitidas.find((f) => f.id === chamada.name)
      const bloco = document.createElement('div')
      bloco.textContent = `O agente quer executar "${ferramenta?.nome ?? chamada.name}" com ${JSON.stringify(chamada.input)}.`
      const btnAprovar = document.createElement('button')
      btnAprovar.textContent = 'Aprovar'
      const btnRecusar = document.createElement('button')
      btnRecusar.textContent = 'Recusar'
      bloco.append(btnAprovar, btnRecusar)
      painel.appendChild(bloco)

      btnAprovar.addEventListener('click', async () => {
        painel.hidden = true
        const syncStore = createSyncConfigStore()
        const localStore = createLocalConfigStore()
        const estadoAnterior = (await syncStore.get()).controleProcessos.favoritos.itens
        try {
          const resultado = await executarFerramenta(chamada.name, chamada.input, { syncStore, localStore })
          const local = await localStore.get()
          await localStore.set({
            ...local,
            agenteIAHistoricoDesfazer: registrarAcaoParaDesfazer(
              local.agenteIAHistoricoDesfazer ?? [],
              { descricao: `Executou "${chamada.name}"`, ferramenta: chamada.name, estadoAnterior },
              new Date().toISOString()
            ),
          })
          const resultados: BlocoConteudo[] = [{ type: 'tool_result', tool_use_id: chamada.id, content: JSON.stringify(resultado) }]
          resolve(await rodarTurno([...mensagensAteAqui, { role: 'user', content: resultados }]))
        } catch (error) {
          const resultados: BlocoConteudo[] = [{ type: 'tool_result', tool_use_id: chamada.id, content: String(error), is_error: true }]
          resolve(await rodarTurno([...mensagensAteAqui, { role: 'user', content: resultados }]))
        }
      })

      btnRecusar.addEventListener('click', async () => {
        painel.hidden = true
        const resultados: BlocoConteudo[] = [{ type: 'tool_result', tool_use_id: chamada.id, content: 'Usuário recusou executar esta ação.', is_error: true }]
        resolve(await rodarTurno([...mensagensAteAqui, { role: 'user', content: resultados }]))
      })
    })
  })
}

function atualizarCustoNaTela(local: Awaited<ReturnType<ReturnType<typeof createLocalConfigStore>['get']>>): void {
  const elemento = document.getElementById('custo-acumulado')
  if (!elemento) return
  const totalUsd = Object.entries(local.agenteIAUsoAcumulado?.porModelo ?? {}).reduce(
    (soma, [modelo, uso]) => soma + calcularCustoUsd(modelo, uso.inputTokens, uso.outputTokens),
    0
  )
  elemento.textContent = `Custo acumulado nesta máquina: US$ ${totalUsd.toFixed(4)}`
}

document.getElementById('form-mensagem')?.addEventListener('submit', async (evento) => {
  evento.preventDefault()
  const campo = document.getElementById('campo-mensagem') as HTMLInputElement
  const texto = campo.value.trim()
  if (!texto) return
  adicionarMensagemNaTela('usuario', texto)
  campo.value = ''
  try {
    await rodarTurno([{ role: 'user', content: [{ type: 'text', text: texto }] }])
  } catch (error) {
    console.error('[SEIRMG] Falha no turno do Agente de IA:', error)
    adicionarMensagemNaTela('erro', 'Algo deu errado. Veja o console pra detalhes.')
  }
})

createLocalConfigStore()
  .get()
  .then(atualizarCustoNaTela)
  .catch((error) => console.error('[SEIRMG] Falha ao carregar custo acumulado:', error))
```
